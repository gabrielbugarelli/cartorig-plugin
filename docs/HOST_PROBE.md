# CartoRig Milestone A — Windows Fusion Studio 20 diagnostic build

**This installs only an independent, read-only host API diagnostic. It does not create a CartoRig scene, node, map, camera, style, preset or render. It is not a V1 alpha implementation, an acceptance test or a stable release.**

## Installation (GUI only)

1. Download the `CartoRig-HostProbe-0.1-win64.exe` file from the successful `Milestone A Host Probe Windows` GitHub Actions build artifact for its commit, alongside its `SHA256SUMS.txt` and `manifest.json`.
2. Optionally verify SHA-256 using Windows Explorer or PowerShell. No Python, compiler, SDK or Natural Earth dataset is required for this *diagnostic*.
3. Close Resolve; double-click the installer, follow the Windows wizard and restart DaVinci Resolve Studio 20.
4. Create or open a **disposable test project** with a Fusion Composition, switch to Fusion, then open **Workspace → Scripts → Comp → CartoRig Host Probe**.
5. Click **Run Diagnostics** and then **Save Report**. The report saves into your Windows TEMP directory. It contains reported API availability, Resolve version if exposed and a node count; it does **not** include node names, project paths or project contents.
6. Share the report and report any UI errors as well as a screenshot of the window if possible.

## Uninstall

Use Windows Settings → Installed Apps → CartoRig Host Probe → Uninstall. The uninstaller deletes only the dedicated diagnostic script and its own local documentation. It does not touch projects, other scripts, the Resolve installation, CartoRig user content, or the Windows registry outside its own entry.

## Why this is the first host check

The supported Fusion Studio 20 host must confirm the exact UIManager, composition API, graph and persistence integration points before code that mutates a user's graph is installed. The diagnostic never claims `A01`–`B20` or core product features are `PASS`. Host-dependent tests remain `NOT RUN` until real, integrated CartoRig nodes can be exercised.

Build generated by **GitHub Actions on free standard Windows runner**, not a developer PC. The `release.yml` stable gate is separate and remains closed.
